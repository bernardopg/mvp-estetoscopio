# 🔌 API Reference

<Callout type="info" title="API RESTful">
  Documentação completa das rotas de API disponíveis no MVP Estetoscópio.

---

## 🔐 Autenticação

Todas as rotas protegidas requerem um token JWT válido enviado via cookie `token`.

### Base URL

```
http://localhost:3000/api
```

---

## 📝 Endpoints

### Autenticação

<Card title="POST /api/auth/signup">

Cria uma nova conta de usuário.

**Request Body**:

```json
{
  "name": "João Silva",
  "email": "joao@example.com",
  "password": "senha123"
}
```

**Response** (201 Created):

```json
{
  "message": "Usuário criado com sucesso",
  "user": {
    "id": 1,
    "name": "João Silva",
    "email": "joao@example.com"
  }
}
```

**Errors**:

- `400`: Dados inválidos ou incompletos
- `409`: Email já cadastrado
- `500`: Erro interno do servidor

</Card>

<Card title="POST /api/auth/login">

Realiza login e retorna token JWT em cookie.

**Request Body**:

```json
{
  "email": "joao@example.com",
  "password": "senha123"
}
```

**Response** (200 OK):

```json
{
  "message": "Login bem-sucedido",
  "user": {
    "id": 1,
    "name": "João Silva",
    "email": "joao@example.com"
  }
}
```

**Errors**:

- `400`: Email ou senha ausentes
- `401`: Credenciais inválidas
- `500`: Erro interno do servidor

</Card>

<Card title="POST /api/auth/logout">

Realiza logout removendo o cookie de autenticação.

**Response** (200 OK):

```json
{
  "message": "Logout realizado"
}
```

**Errors**:

- `500`: Erro interno do servidor

</Card>

- `401`: Não autenticado
- `403`: Baralho não pertence ao usuário
- `404`: Baralho não encontrado
- `500`: Erro interno do servidor

<Card title="POST /api/decks/[id]/progress">

🔒 **Rota Protegida**

Atualiza o progresso após revisar um card.

**URL Parameters**:

- `id`: ID do baralho

**Request Body**:

```json
{
  "cardId": 1,
  "quality": 4
}
```

**Quality Scale**:

- `0`: Resposta completamente errada
- `1`: Resposta errada mas familiar
- `2`: Resposta errada mas fácil de lembrar
- `3`: Resposta correta com dificuldade
- `4`: Resposta correta com hesitação
- `5`: Resposta perfeita

**Response** (200 OK):

```json
{
  "message": "Progresso atualizado",
  "progress": {
    "card_id": 1,
    "ease_factor": 2.6,
    "interval": 6,
    "repetitions": 1,
    "next_review": "2024-02-02T10:00:00Z",
    "last_reviewed": "2024-01-27T10:00:00Z"
  }
}
```

**Errors**:

- `400`: Dados inválidos
- `401`: Não autenticado
- `403`: Card não pertence ao usuário
- `404`: Card não encontrado
- `500`: Erro interno do servidor

</Card>

### Upload

<Card title="POST /api/upload">

🔒 **Rota Protegida**

Faz upload de arquivo (imagem ou áudio).

**Content-Type**: `multipart/form-data`

**Form Data**:

- `file`: Arquivo a ser enviado
- `type`: "image" ou "audio"

**Image Formats**: JPG, JPEG, PNG, GIF, WebP (máx 5MB)
**Audio Formats**: MP3, WAV, OGG, M4A (máx 10MB)

**Response** (200 OK):

```json
{
  "url": "/uploads/images/1234567890-foto.jpg"
}
```

**Errors**:
- `400`: Arquivo não enviado ou tipo inválido
- `401`: Não autenticado
- `413`: Arquivo muito grande
- `415`: Formato não suportado
- `500`: Erro ao salvar arquivo

</Card>

### Anki (Importação/Exportação)

<Card title="POST /api/anki/import">

🔒 **Rota Protegida**

Importa um arquivo `.apkg` e retorna as flashcards convertidas (preview — a
criação do baralho é feita em seguida via `POST /api/decks`).

**Content-Type**: `multipart/form-data`

**Form Data**:

- `file`: Arquivo `.apkg` a ser importado

**Response** (200 OK):

```json
{
  "success": true,
  "data": {
    "deck": "Nome do Baralho",
    "flashcards": [
      { "front": "Pergunta", "back": "Resposta", "tags": ["tag1"] }
    ],
    "total": 1
  }
}
```

**Errors**:
- `400`: Arquivo ausente, extensão diferente de `.apkg` ou pacote inválido/corrompido (a mensagem detalha a causa do parse)
- `401`: Não autenticado
- `422`: Nenhuma flashcard compatível (notas sem campos Front/Back ou Frente/Verso)
- `500`: Erro inesperado ao processar o arquivo

</Card>

<Card title="GET /api/anki/export?deckId={id}">

🔒 **Rota Protegida**

Exporta um baralho no formato `.apkg`.

**Response** (200 OK): binário `application/zip` com
`Content-Disposition: attachment; filename="nome_do_baralho.apkg"`

**Errors**:
- `401`: Não autenticado
- `404`: Baralho não encontrado
- `500`: Erro ao gerar o arquivo

</Card>

<Callout type="info">
  **Formato do pacote** — o `.apkg` gerado usa um formato interno em ZIP:
  `collection.anki2` (JSON com `decks` e `models`) e `notes.json` (notas com
  campos `Front`/`Back` e tags). O round-trip export → import é coberto por
  testes automatizados (`src/lib/__tests__/anki-roundtrip.test.ts`).
</Callout>

## 🔒 Segurança

### Autenticação JWT

<Callout type="info" title="JSON Web Token">
  O sistema usa JWT (JSON Web Token) para autenticação stateless.
</Callout>

**Token Storage**: Cookie HTTP-only chamado `token`
**Token Duration**: 24 horas
**Token Refresh**: Não implementado (requer novo login)

### Headers Necessários

Para rotas protegidas, o cookie `token` deve estar presente:

```http
Cookie: token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### Rate Limiting

<Callout type="warning">
  Atualmente não há rate limiting implementado. Planejado para v1.2.
</Callout>

## 📊 Códigos de Status

<Card title="Status HTTP">
  - `200 OK`: Requisição bem-sucedida - `201 Created`: Recurso criado com
  sucesso - `400 Bad Request`: Dados inválidos ou ausentes - `401 Unauthorized`:
  Não autenticado - `403 Forbidden`: Sem permissão para acessar recurso - `404
  Not Found`: Recurso não encontrado - `409 Conflict`: Conflito (ex: email já
  cadastrado) - `413 Payload Too Large`: Arquivo muito grande - `415 Unsupported
  Media Type`: Formato não suportado - `500 Internal Server Error`: Erro no
  servidor
</Card>

## 🧪 Exemplos de Uso

### cURL

<CodeBlock title="Criar conta" language="bash">
  {`curl -X POST http://localhost:3000/api/auth/signup \\
  -H "Content-Type: application/json" \\
  -d '{
    "name": "João Silva",
    "email": "joao@example.com",
    "password": "senha123"
  }'`}
</CodeBlock>

<CodeBlock title="Fazer login" language="bash">
  {`curl -X POST http://localhost:3000/api/auth/login \\
  -H "Content-Type: application/json" \\
  -d '{
    "email": "joao@example.com",
    "password": "senha123"
  }' \\
  -c cookies.txt`}
</CodeBlock>

<CodeBlock title="Listar baralhos" language="bash">
  {`curl -X GET http://localhost:3000/api/decks \\
  -b cookies.txt`}
</CodeBlock>
